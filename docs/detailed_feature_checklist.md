### `src/detect_joint_movement_with_hip_stay.py` 機能チェックリスト

| カテゴリ | 機能 | 詳細な仕様 | 確認方法 |
| :--- | :--- | :--- | :--- |
| **1. 姿勢監視 (`PostureMonitor`)** | 前傾姿勢の判定 | 体の傾き(BODY_TILT)が150度以下、または首の角度(NECK_TRUNK_ANGLE)が150度以下、または肩(SHOULDER)が屈曲(FLEXION)状態の場合に、スコアに基づいて前傾と判定する。 | 単体テストで、特定の角度・状態を持つ`analysis_results`を入力し、`is_forward_leaning`の返り値（True/Falseとスコア）が期待通りか検証する。 |
| | 長時間の前傾姿勢アラート | 監視期間(`monitoring_duration`)中、前傾姿勢のフレームの割合が閾値(`alert_threshold`)を超えた場合にアラートを生成する。 | 単体テストで、時系列データ（`PostureSnapshot`のリスト）を模擬的に`update`メソッドに与え、アラートメッセージが期待通りに生成されるか検証する。 |
| | アラートのクールダウン | 一度アラートが生成された後、一定期間(`alert_cooldown`)は次のアラートを抑制する。 | 単体テストで、アラート条件を満たしてもクールダウン期間中は新たなアラートが生成されないことを確認する。 |
| | 状態取得 | `get_status()`メソッドが現在の監視期間、前傾割合、平均スコア、サンプル数を正しく返す。 | 単体テストで、`update`を数回呼び出した後、`get_status`の返り値が正しいか検証する。 |
| **2. 滞在検知 (`HipBasedStayDetector`)** | 腰中心の座標抽出 | 左右の腰のランドマークから中心座標を計算する。片方の腰しか見えない場合でも、その腰の座標を返す。 | 単体テストで、両腰、片方の腰、腰なしのランドマークデータを入力し、返される座標と信頼度が正しいか検証する。 |
| | 人物スケール計算 | 正規化のため、人物の大きさ（スケール）を計算する。計算基準として「胴体(torso)」「肩幅(shoulder)」「画面(screen)」を選択できる。 | 単体テストで、特定のランドマークデータに対し、各基準でのスケール計算結果が正しいか検証する。 |
| | 移動検知ロジック | 以下の複合条件で移動を検知する：<br>1. 正規化された移動距離の急増(`spike_threshold`)<br>2. 人物スケールの不安定性(`stability_threshold_px`) | 単体テストで、移動距離やスケールが閾値を超える時系列データを入力し、移動が検知される（状態が`POTENTIAL_MOVE`に遷移する）ことを確認する。 |
| | 移動確定の猶予期間 | 移動を検知しても即座に滞在をリセットせず、猶予期間(`grace_period_sec`)を設け、その間の移動フレームの割合(`confirmation_ratio`)が閾値を超えた場合に移動を確定する。 | 単体テストで、一時的な移動（すぐ静止）と継続的な移動のシナリオを与え、前者では滞在が継続し、後者ではリセットされることを確認する。 |
| | 長時間滞在アラート | 滞在時間(`stay_duration`)が閾値(`stay_threshold_sec`)を超えた場合にアラートを生成する。 | 単体テストで、静止状態を継続させるデータを入力し、滞在時間が閾値を超えたタイミングでアラートが返されることを確認する。 |
| | 状態取得 | `get_current_status()`が現在の腰位置、滞在時間、信頼度、滞在状態(`state`)を正しく返す。 | 単体テストで、`update`を数回呼び出した後、`get_current_status`の返り値が正しいか検証する。 |
| **3. 膝角度監視 (`KneeAngleMonitor`)** | 信頼度に基づく角度フィルタリング | 膝関節を構成する3点（腰、膝、足首）の信頼度がすべて閾値(`confidence_threshold`)以上の場合のみ、角度データを採用する。 | 単体テストで、信頼度が閾値未満のランドマークデータを与えた場合、角度データが蓄積されないことを確認する。 |
| | 秒単位での中央値集計 | 1秒ごとに収集した膝角度の中央値を計算し、履歴として保持する。 | 単体テストで、1秒間に複数の角度データを入力し、秒が切り替わるタイミングで正しい中央値が計算・記録されることを確認する。 |
| | 移動平均の計算 | 過去N秒(`moving_window_seconds`)の中央値履歴から移動平均を計算する。 | 単体テストで、複数秒にわたるデータを入力し、移動平均が正しく計算されることを確認する。 |
| | 膝角度低下アラート | 秒ごとの中央値、または移動平均が閾値(`threshold_deg`)を下回った場合にアラートを生成する。 | 単体テストで、角度が閾値を下回るデータを入力し、アラートメッセージが期待通りに生成されることを確認する。 |
| | アラートメッセージ保持 | `get_current_alert()` が、最後に生成されたアラートメッセージを保持し、次のフレームで取得できる。 | 単体テストで、アラート生成後に `get_current_alert()` を呼び出し、メッセージが返されることを確認する。 |
| **4. 汎用姿勢分析** | 骨格推定 | `PoseEstimator`がビデオフレームからMediaPipeの33個のランドマークを抽出する。 | 統合テストで、ビデオを入力した際に`landmarks`が`None`でないことを確認する。（単体テストではMediaPipeをモック） |
| | 関節角度・状態分析 | `MovementAnalyzer`がランドマークから各関節の角度と状態（屈曲、伸展、静止など）を計算する。 | 既存の`test_movement_analyzer.py`がパスすること。 |
| | 首振り検知 | `HeadShakeDetector`が首の左右・上下の動きを検知し、アラートを生成する。 | 既存の`test_head_shake_detector.py`がパスすること。 |

| | 描画：分析結果 | `draw_analysis_results`が各関節の角度や状態をテキストで描画する。 | 統合テストで生成されたビデオに関節情報が描画されていることを確認する。 |
| | 描画：アラート | `draw_posture_alerts`が姿勢・膝・首振りのアラートを画面上部に描画する。 | 統合テストで、アラート発生時にビデオにメッセージが描画されることを確認する。 |
