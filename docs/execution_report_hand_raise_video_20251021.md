## 🛠️ 技術的な詳細

### 処理中に修正された問題

1. **FPS型変換エラー**
   - **問題**: `fps`がnumpy配列のため、フォーマット文字列エラーが発生
   - **修正**: `float(fps)`で明示的に変換

2. **関数シグネチャの不一致**
   - **問題**: `draw_analysis_results()`が異なるパラメータで呼び出されていた
   - **修正**: 関数署名に`hand_statuses`パラメータを追加

### 処理パイプラインの構成要素

```
1. ビデオキャプチャ (OpenCV)
   ├─ フレーム読み込み
   └─ フレームリサイズ

2. ポーズ推定 (MediaPipe)
   ├─ 33個のランドマーク検出
   └─ 信頼度スコア計算

3. 動作分析
   ├─ 関節角度計算
   ├─ 体の傾き分析
   ├─ 首振り検知
   ├─ 手上げ検知

4. CSV出力
   ├─ 194カラムのデータセット
   └─ フレームごとの詳細情報

5. 動画出力
   ├─ アノテーション描画

   └─ MP4形式で保存
```

## 📈 データセット構造

### CSV 194カラムの構成

#### グループ1: メタデータ（2カラム）
- `timestamp`: 動画内の時刻
- `frame_number`: フレーム番号

#### グループ2: 関節角度（24カラム）
- 右肘・左肘・右肩・左肩・右腰・左腰・右膝・左膝の角度と状態
- 膝関節の信頼度スコア

#### グループ3: 姿勢情報（8カラム）
- 体幹傾き角度・状態
- 首・体幹角度・状態
- 首水平回転角度・状態
- 首縦方向ノッド角度・状態

#### グループ4: 検出フラグ（7カラム）
- 首振り検知（水平・垂直）
- 首振りアラート
- 前傾検知
- 前傾スコア・比率

#### グループ5: 腰滞在情報（7カラム）
- 腰中心座標（x, y）
- 滞在時間
- 腰信頼度
- 長期滞在フラグ
- 腰検出器状態

#### グループ6: ランドマーク座標（132カラム）
- 33個のキーポイント × 4値（x, y, z, visibility）
- NOSE, EYE, EAR, MOUTH, SHOULDER, ELBOW, WRIST, HIP, KNEE, ANKLE等
